## 四条渠道逐一拆：门槛在哪，坑在哪

### Apple 官网：卡最干净，卡在账单地址

有教程作者完整走过这条路，配置是招商银行全币种 Visa 加一个网络生成的免税州地址。流程不复杂：进 Apple 官网礼品卡页面点 Buy，发送方式选 Email（选 Mail 是寄实体卡，别选错），面额可选 $25/$50/$100，也能点 Other Amount 自定义，**最低 $10**；收件人、发件人全填自己；结账时支付方式选 Credit or Debit Card，支持 Visa、Mastercard、AMEX、Discover、UnionPay。

决定你交不交税的是账单地址那一步。填俄勒冈（Oregon）这类免税州，下单页会显示 Subtotal $10、Estimated Tax $0，实付就是 $10。地址填加州，就会按州加税。付完显示 Processing，「Usually arrives within 1 hour」，卡密以邮件形式发到收件邮箱，标题形如「xx sent you an Apple Gift Card」。

门槛也在这里：你得有一张能过美国地址的卡，还得自己搞定一个可用的免税州地址。国内不少双币卡在这一步被拒。

### 支付宝 Pockyt：$2 起，但入口得先收藏下来

这条路全程在支付宝里，人民币结算。路径是：支付宝左上角地区切到「旧金山」→ 底部「优惠」→「大牌礼卡」（页面标低至 9 折）→ 拉到页面底部点「更多大牌折扣礼卡，点击查看」→ 进 Pockyt Shop → 选 App Store & iTunes US → 输入金额（$2 到 $500）→ 支付宝付款 → 订单页直接显示卡密。

很多人说搜不到 Pockyt，原因是入口位置比较深。进 Pockyt Shop 后第一件事是点右上角星标收藏，页面写着「点击收藏后在国内城市就能找到」，收藏过之后切回国内也能从收藏进。有教程作者实测买 $2，下单即出卡密，状态直接是「订单完成」，比官网等邮件还快。

金额填错或者付款后没出卡，未成功会自动退款，退款到账后重买一次就行。

## 兑换会不会被扣税：两种说法都摆在这里

这是全网教程里最容易踩空的一处，两种口径都存在，我不替任何一方下结论。

一种说法来自账号星球的商品说明：兑换时 Apple 会按你 Apple ID 注册州的税率，从卡面值里自动扣税，$10 卡在加州（约 8.5%）实际到账可能只有 $9.21 左右；余额因此不够付订阅，不算平台售后范围。它建议买大一号面值，或者注册 ID 时直接选免税州。

另一种来自上面那位官网实测的教程作者：税是在**购买环节**按账单地址收的，填免税州，下单页 Estimated Tax 就是 $0，$10 卡到手就是 $10 面值。

两条说的环节不同，现有信息判断不了哪个绝对正确，也可能取决于渠道和账号注册州。稳妥做法两头都照顾：Apple ID 注册地址选免税州（俄勒冈 OR、蒙大拿 MT、新罕布什尔 NH、特拉华 DE、阿拉斯加 AK），订阅金额贴着余额的话买大一号面值。别把 8.5% 当成普遍税率，各州差别很大。

兑换本身没有难度：App Store → 右上角头像 → 「兑换充值卡或代码」→ 粘贴 16 位卡密或扫码 → 确认，余额即时到账，全程不到 30 秒。

有一条硬限制必须说：**美区卡只能充美区 Apple ID**。国区 ID 兑换直接失败，账号星球的商品页也标着「国区勿拍」。港区、日区账号同样用不了。
